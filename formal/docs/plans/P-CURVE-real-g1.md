# P-CURVE - a real-curve G1 model. The last blocker to the first real proof.

Status: READY and **highest value in the project right now.** P-4a2 closed the `EnvAgrees`
blocker to P5; `Eip2537.Holds` is the only one left. Without it, the four-way bundle
`BlkIsEmitter /\ SupportedS /\ EnvAgrees /\ Eip2537.Holds` has **no witness**, so
`finalPairing_spec` - the first real proof and our only proof-speed calibration point -
cannot be attempted end to end.

## Why it is smaller than "no BLS12-381 model" sounds

R-61 established this, and P-AST confirmed the arithmetic half is already done:

* **mathlib already has the group law** on affine Weierstrass points
  (`Mathlib/Algebra/Elliptic/Affine/Point.lean:805`).
* **`Midfall/Yul/Externals.lean` already computes** G1 addition, MSM and subgroup checks -
  it is the EIP-2537 relation, byte-exact, and it is *tested*.
* **The pairing stays a parameter.** Define `product` from it, so the `pairing2` clause holds
  **by construction** rather than needing a pairing implementation.

So the work is: a G1 type whose points are curve points with a real codec, plus lemmas tying
`affineAdd`/`affineSmul` to mathlib's group law and to what `Externals.lean` computes.

## What `Holds` actually needs - measured, not guessed

P-AST2/P-AST3a measured which clauses fail at the exponent model. **`g1Valid`, `g1Add` and
`g1Msm1` are about the G1 codec and the precompile frames - R-61's cheaper route fixes only
`pairing2`.** So the deliverable must discharge all of:

| clause | what it needs |
|---|---|
| `g1Valid` | `g1Of? (c.toEip Q)` decodes, and `g1PointMsmValid` - fails for every non-identity exponent today |
| `g1Add` | real 0x0b semantics over curve addition |
| `g1Msm1` | real 0x0c semantics, scalar times point |
| `g2Valid` | the `encG2` shape plus a real G2 point |
| `pairing2` | satisfied by defining `product` from the parameterised pairing |
| `g1Decodes` | the codec round-trip on real compressed points |

## Deliverable

1. `Midfall/Instances/Bls12_381G1.lean` (or extend the existing `Bls12_381.lean` - your call,
   say which and why): G1 as the r-torsion subgroup generated by the standard point on
   `y^2 = x^3 + 4`, with a codec serialising affine coordinates and `Group G1` +
   `PrimeOrderWith G1 r` instances.
2. Lemmas that the group operations agree with **mathlib's** group law and with
   **`Externals.lean`'s** EIP-2537 computations - the second is the one that matters for
   `Holds`, since `Holds` is about precompile frames.
3. A `Surface` instance at the real curve, and **one declaration** exhibiting the four-way
   bundle. P-AST3a warned: it must be a single joint exhibit, not four separate ones -
   individually-inhabited-jointly-empty is the failure that made a headline hypothesis
   uninhabited (R-60 S1).
4. `gap_holds_unexhibited` deleted once it is genuinely discharged, and the bundle gate
   updated so the gap cannot silently return.

## Constraints

* **`Instances/` is the only place a concrete curve may live** (D-P17). Theorem-bearing
  files must not import it - `checks.sh` enforces direct imports only, so keep it clean.
* **`decide` reduces for exponentiation at 255-bit `r` but not for inversion** (P-4a2
  measured). Carry inverses as literals proved by a multiplication.
* **`native_decide` is confined to `Instances/`** - that is where it belongs here, but every
  use must be a gate, not a proof of a headline statement.
* **Numeric spelling is invisible to every AST relation** (P-AST2/P-AST3a). Not likely to
  bite here, but do not reach for a token gate if it does.
* Do NOT edit `Statements.lean`, Rust, or `vendor/`. Do NOT git add or commit.
* Verify existence with `#check`, not grep piped through `head`. **Never perturb the working
  tree in place** (R-54). Register modules (R-50). Numbers from `lake build` and
  `scripts/checks.sh`.
* **D-P23 / R-41**: every claim needs a witness AND a demonstrated failure mode.

## If it turns out to be much bigger than R-61 estimated

**Stop and report rather than shipping a partial model that pretends to satisfy `Holds`.** A
`Holds` exhibit that discharges five of six clauses while the sixth is quietly weakened is
exactly the vacuity class this project has now found seven times. Say which clause resists
and what it would take.
